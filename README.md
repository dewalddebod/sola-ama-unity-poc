# SOLA Ama Unity POC

Playable Unity 6.3 URP/WebGL graphics and integration experiment. Drag or swipe to orbit the actual textured Ama Meshy 6 Lite character; scroll to zoom on desktop. The idle animation loops.

This is **not** the SOLA avatar creator. Clothing is fused to the character mesh; outfit swaps, sitting deformation, and phone-native performance are not validated. The build was checked in headless desktop Chromium and an Android-sized browser emulation, not on a physical phone.

Built from the isolated `SOLA-Ama-Unity-POC` scratch project. No source assets from the accepted SOLA Unity project were modified.
